# Contributing

Contributions are welcome for language interpretation, safe compression, benchmark design, and additional agent integrations.

## Development

```bash
npm install
npm run check
```

Keep changes small and include tests. Do not add slang mappings that depend on stereotypes or target protected groups. Preserve exact technical information in every compression path.

For benchmark changes, include the task source, scoring rule, model, Claude Code version, and repeated-run count.
